# Rediseño — Fase D2: Home (hero circular, categorías destacadas, mensaje promocional) — Plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Agregar una insignia circular del logo al hero, reemplazar
el grid rectangular de categorías por íconos circulares de categorías
destacadas (curadas por el admin), y agregar una barra de mensaje
promocional editable — sin tocar `BenefitsBar`, `CollectionBanners`,
`ReviewsSection` ni la sección "Destacados".

**Architecture:** `categories` gana `is_featured` (columna nueva,
mismo patrón que `products.is_featured` ya existente). Un componente
nuevo (`FeaturedCategories`) sigue el mismo patrón presentacional ya
establecido en B1 (la página resuelve los datos, el componente solo
presenta, degrada con gracia sin contenido). `HeroSection` gana un
elemento posicionado absolutamente para la insignia — sin cambiar su
lógica de fallback existente. La barra de mensaje promocional es un
componente nuevo y minúsculo agregado a `PublicLayoutShell`, mismo
patrón de "oculto si no está configurado" ya usado en toda la Fase B/D.

**Tech Stack:** Next.js App Router (Server + Client Components),
Supabase (Postgres, vía MCP), react-hook-form + zod, `lucide-react`.

## Global Constraints

- Todo el producto en español (UI, mensajes).
- `BenefitsBar`, `CollectionBanners`, `ReviewsSection` y la sección
  "Destacados" de productos NO se tocan en este plan.
- `CategoryGrid` no se elimina del código, solo deja de usarse en la
  home — puede quedar disponible para otro uso futuro.
- El mensaje promocional es texto libre sin lógica de cupones reales
  — fuera de alcance permanente, ya decidido.
- Toda migración de Supabase se crea y aplica con el MCP de Supabase.
- Los formularios que suben archivos ya establecieron el patrón
  `try/catch` en su `onSubmit` — no se rompe ese patrón en
  `CategoriaForm` al agregar el campo nuevo.

- [ ] **Step 3: Crear `PromoBar`**

Crea `src/components/layout/promo-bar.tsx`:

```tsx
import { createClient } from "@/lib/supabase/server";
import { STORE_SETTINGS_KEYS } from "@/lib/validation/store-settings";

export async function PromoBar() {
  const supabase = await createClient();
  const { data } = await supabase
    .from("store_settings")
    .select("value")
    .eq("key", STORE_SETTINGS_KEYS.mensajePromocional)
    .maybeSingle();

  const mensaje = data?.value ? String(data.value).trim() : "";
  if (!mensaje) return null;

  return (
    <div className="bg-brand-rosa px-4 py-2 text-center text-xs font-medium text-brand-crema sm:text-sm">
      {mensaje}
    </div>
  );
}
```
